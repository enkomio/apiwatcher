# apiwatcher

`apiwatcher` is an Intel Pin pintool that logs calls from the instrumented process to routines implemented by imported DLLs/images.

The tool instruments every `call` instruction, resolves the runtime branch target with Pin, filters out targets in the main executable, and writes a CSV log.

## Build

Install Intel Pin and build with the Pin SDK make rules:

```powershell
cd pin_tool
$env:PIN_ROOT = "C:\path\to\pin"
make
```

The output library is generated by Pin's build system under `pin_tool/obj-*`.

## Run

```powershell
& "$env:PIN_ROOT\pin.exe" -t .\obj-intel64\apiwatcher.dll -o apiwatcher.csv -- C:\path\to\program.exe
```

By default, only API calls issued by the main executable are logged. To also include calls made by DLLs loaded in the process:

```powershell
& "$env:PIN_ROOT\pin.exe" -t .\obj-intel64\apiwatcher.dll -o apiwatcher.csv -only_main 0 -- C:\path\to\program.exe
```

## CSV columns

- `thread_id`
- `call_site`
- `caller_image`
- `caller_routine`
- `target`
- `target_image`
- `target_routine`
